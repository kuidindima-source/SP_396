# Правила разработки для CalculatorApp

## WebView2 и Frontend
- **Навигация:** Всегда использовать чистые пути без query-параметров (например, `http://calculator.app/index.html`). Query-параметры ломают виртуальный маппинг папок.
- **Vite:** Поле `base` в `vite.config.ts` должно быть строго `./`.
- **Протокол:** Предпочтительно использовать `http` для виртуальных хостов во избежание проблем с TLS/SSL в локальной среде.

## C# и WinForms
- **Инициализация WebView2:** 
  1. Подписка на события (InitializationCompleted, NavigationCompleted).
  2. Вызов `EnsureCoreWebView2Async`.
- **Кэширование:** Принудительная очистка кэша через удаление папки в `%LOCALAPPDATA%` предпочтительнее, чем программная очистка через API WebView2 (которая может блокировать запуск).

## Процесс сборки
- Запрещено изменять логику синхронизации в `build.bat`, которая удаляет папку `wwwroot` перед копированием. Это гарантирует отсутствие "мусорных" файлов от прошлых сборок.
